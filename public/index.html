Using the studio

Select or create a character, choose a palette color, then click pixels to paint. The timeline changes the preview frame; effect buttons toggle the preview behavior. Pixel scale and frame rate are editable.

Export PNG downloads the current transparent frame. This browser editor stores drafts locally. To create production PNG sequences and ProRes-alpha MOV files, create source in characters/<name>/, then run npm run validate -- <name> and npm run render -- <name>.
