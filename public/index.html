    Using the studio

    Choose a palette color and paint the canvas. Painting an already-matching pixel is now a no-op; only the eraser removes pixels. Use Undo whenever you need to recover an edit.

    Pick samples a color from the next canvas pixel you click. The custom color control adds colors to the active character palette.

    Export animation downloads either a transparent animated PNG or a transparent sprite sheet, depending on the timeline menu. Export current frame downloads a still PNG.

    For Premiere-ready ProRes 4444, production source still lives under characters/<name>/. Run npm run validate -- <name> and npm run render -- <name>, then import the generated *_loop_30s.mov.
