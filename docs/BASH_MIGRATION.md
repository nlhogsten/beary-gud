# Bash migration

`npm run import-bash -- old.sh name` recognizes a quoted `canvas=(...)` matrix and the common alternating `offset` pattern. It copies the matrix into an editable character source and records a deterministic smoke rule.

It does **not** run Bash, shell substitutions, loops, or commands. Unsupported scripts are rejected instead of being guessed or executed. Rebuild their visual behavior with frames and effects after importing the base art.
